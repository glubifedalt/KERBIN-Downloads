# KERBIN

**AI-generated project, built with human direction.**

Your own streaming orbit: a Kerbin-inspired client and host for 111477 streams, using your own TMDB key. Independent of Jellyfin.

## Downloads

Open [Releases](https://github.com/glubifedalt/KERBIN-Downloads/releases/latest). Start with a Windows or Linux **Host** bundle; device **Client** packages connect to that running host.

- Windows / Linux server bundles include Node, FFmpeg, cloudflared and client packages.
- Windows desktop EXE and Linux AppImage clients.
- Android / Android TV APK.
- Samsung Tizen WGT: requires TV-bound Samsung signing. The Windows host includes a guided installer.
- iOS IPA: requires your Apple sideload signature. Safari Add to Home Screen is also available.

Account settings contain setup and installation tutorials. Keep the host computer online. Initial setup requires your TMDB v3 key and a Kerbin owner account; remote HTTPS hosting is optional.

Designed for one or two viewers. Experimental NVIDIA AI enhancement is optional, needs a separate runtime and suitable hardware, and falls back to ordinary playback when it cannot keep up. Provider or network availability can still interrupt playback.

This repository distributes release builds. Packages include their license notices; checksums accompany releases. The application source repository and its development history remain private. Server bundles include their application scripts and license notices.

An unofficial fan project, not affiliated with KSP, TMDB, 111477 or the device platforms.
